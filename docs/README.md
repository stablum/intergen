# Intergen documentation

The documentation is organized by purpose so that the project overview,
hands-on instructions, keyboard reference, and implementation details do not
compete for attention.

## Start here

- [User guide](USER_GUIDE.md) — requirements, running Intergen, the main
  workflow, configuration, presets, screenshots, Blender export, and developer
  verification
- [Keybinding reference](KEYBINDINGS.md) — the canonical list of keyboard
  controls, with all F-modes collected in one place

## Go deeper

- [Spawn geometry guide](SPAWN_GEOMETRY_GUIDE.md) — an illustrated explanation
  of attachments, placement, scaling, offsets, spawning, and generation LFOs
- [Data model](DATA_MODEL.md) — the technical reference for runtime scene state,
  configuration, presets, and derived values

For a visual overview of the project, return to the [project README](../README.md).
